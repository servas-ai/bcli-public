**bcli v0.14.0-rc.2** is the first public release candidate of the command-line client for
[servas.ai](https://servas.ai) Browser as a Service: real, headed cloud browsers for your agents and tests, driven over
standard CDP — for **Linux, macOS and Windows**.

## Highlights

- **Linux, macOS (Apple silicon) and Windows** — single executables, no dependencies.
- **OIDC sign-in** via `auth.servas.ai` (`bcli login`) — no VPN, no API keys.
- **One command to a real browser:** `bcli session create --wait` → `connectOverCDP(cdp_url)` → `bcli session stop`.
- **Live view and hand-over** in your own browser (`view_url`).
- **Persistent profiles**, **your own exit IP** ([baas-exit-docker](https://github.com/servas-ai/baas-exit-docker)),
  **localhost tunnels**, **GPU sessions**, **session audio**.
- **Local mode on every platform** with an encrypted credential vault: `bcli vault unlock` once, the fill extension
  is built into bcli; `bcli vault unlock --session <id>` brings the vault to a cloud session.
- **Agent-ready:** `agent-web` helper (bash + PowerShell) on top of agent-browser, a Claude Code skill and an
  `AGENTS.md` snippet in this repository.
- **Signed self-update** (`bcli update`) on Linux and macOS.

Step-by-step instructions for every OS: [docs/installation.md](https://github.com/servas-ai/bcli-public/blob/main/docs/installation.md).

```bash
# Linux example
VERSION=v0.14.0-rc.2; ARCH=amd64
BASE=https://github.com/servas-ai/bcli-public/releases/download/$VERSION
curl -fsSLO "$BASE/bcli-linux-$ARCH" -O "$BASE/SHA256SUMS"
grep " bcli-linux-$ARCH\$" SHA256SUMS | sha256sum --check -
install -D -m 0755 "bcli-linux-$ARCH" ~/.local/bin/bcli
```

## Verify

Always check the binary against `SHA256SUMS` (Linux `sha256sum`, macOS `shasum -a 256`, Windows `Get-FileHash`).
`SHA256SUMS.sig` is the Ed25519 signature of `SHA256SUMS` with the servas.ai CLI release key
([keys/bcli-release-ed25519.pem](https://github.com/servas-ai/bcli-public/blob/main/keys/bcli-release-ed25519.pem)).

## Get started

```bash
bcli env add cloud --kind cloud --endpoint https://api.baas.servas.ai && bcli env use cloud
bcli login
bcli session create --wait
```

## Known limitations

- **Release candidate** — please report problems via [Issues](https://github.com/servas-ai/bcli-public/issues).
- **macOS:** `bcli-darwin-arm64` (and the macOS bundle) was built but **has not been run on Apple silicon** for this
  release candidate — treat it as a preview. It is not notarized and not signed with an Apple Developer ID: remove the
  quarantine flag after verifying the checksum.
- **Windows:** not Authenticode-signed (SmartScreen warns on first start). No self-update (`bcli update --check` says
  so; re-run the installer) and no service autostart (run `bcli daemon start` after logon). `bcli assist` and
  `bcli audio` are not available. The local daemon and vault only work from non-elevated terminals in the same logon
  session, and not from inside a Windows job such as a scheduled task. Edge shows a "Disable developer mode
  extensions" pop-up for local sessions; close it with ×.
- **Windows ARM64:** no native dialog window (the dialog's WebView2 loader is x64-only).
- **Local mode on Linux and macOS** needs `browser_path` / `BAAS_BROWSER_PATH` pointing to a Chromium-based browser.
