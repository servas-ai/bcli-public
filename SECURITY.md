# Security policy

## Supported versions

Security fixes are released for the latest published version of bcli. `bcli update` installs it, and release builds
check for updates daily.

## Reporting a vulnerability

Please report vulnerabilities **privately** via the contact options on [servas.ai](https://servas.ai). Do not open a
public issue for security problems.

Include the output of `bcli version`, your operating system, what you did and what happened. Remove every URL or value
that contains `token=` before sending.

Details on the security model, release signatures and checksum verification: [docs/security.md](docs/security.md).
