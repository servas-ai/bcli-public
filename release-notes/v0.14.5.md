**bcli v0.14.5** brings Bitwarden autofill to **Linux and macOS** from the public release. The Bitwarden bridge is
part of every `bcli` and now runs as your user's background service on all three platforms; the installer sets it
up. Same platforms, same install paths; `bcli update` brings it to an existing install.

## Changes

- **Bitwarden bridge on Linux and macOS** (`bcli bwbridge start | stop | status | remove`): `start` installs the
  bridge as a systemd user service (`bcli-bwbridge.service`, starts with your desktop session) or a LaunchAgent
  (`ai.servas.bcli.bwbridge`, starts at login) and starts it now. Then `bcli vault bw setup` connects your Bitwarden
  account (bitwarden.com, bitwarden.eu or self-hosted) and `bcli vault bw autofill` fills logins in local and cloud
  sessions after you approve each one. Guide: [docs/bitwarden.md](https://github.com/servas-ai/bcli-public/blob/main/docs/bitwarden.md).
- **Installer:** `install.sh` sets up the bridge when you run it in a desktop terminal (`--no-bwbridge` skips it) and,
  on Ubuntu/Kubuntu 23.10–25.10, the AppArmor profile of the approval window when `sudo` needs no password; otherwise
  it prints the command (`bcli bwbridge apparmor | sudo tee /etc/apparmor.d/bcli-prompt …`).
- **`bcli uninstall` on Linux and macOS:** removes the bridge service, stops the background vault and the daemon,
  deletes the unpacked approval window and the `bcli` file (Homebrew: `brew uninstall bcli`); `--purge` also deletes
  the vault, environments and Bitwarden bridge state.
- **`bcli bwbridge`** is listed in the help on every platform; `status` and `start --restart` work on Windows too.

## Install

```bash
# Linux and macOS (in a terminal of your desktop session, so the Bitwarden bridge is set up too)
curl -fsSL https://raw.githubusercontent.com/servas-ai/bcli-public/main/install.sh | sh
```

```powershell
# Windows (normal PowerShell window)
irm https://raw.githubusercontent.com/servas-ai/bcli-public/main/install.ps1 | iex
```

Already installed: `bcli update` (or `brew upgrade bcli`, `scoop update bcli`), then on Linux and macOS
`bcli bwbridge start` once. Homebrew: `brew install servas-ai/tap/bcli`. Scoop:
`scoop bucket add servas https://github.com/servas-ai/scoop-bucket`, then `scoop install servas/bcli`.
Pin this release with `sh -s -- --version v0.14.5` or `$env:BCLI_VERSION = "v0.14.5"`.
Everything else: [docs/installation.md](https://github.com/servas-ai/bcli-public/blob/main/docs/installation.md).

## Verify

The install scripts do this for you. By hand: `SHA256SUMS.sig` is the Ed25519 signature of `SHA256SUMS` with the
servas.ai CLI release key
([keys/bcli-release-ed25519.pem](https://github.com/servas-ai/bcli-public/blob/main/keys/bcli-release-ed25519.pem));
check it with OpenSSL 3 or, on Windows, with
[scripts/windows/verify-release.ps1](https://github.com/servas-ai/bcli-public/blob/main/scripts/windows/verify-release.ps1),
then check the binary against `SHA256SUMS`
([how](https://github.com/servas-ai/bcli-public/blob/main/docs/installation.md#verify-the-signature-of-sha256sums)).

## Known limitations

- The Bitwarden bridge on macOS is built and unit-tested but has not yet been checked on a Mac.
- Unchanged from [v0.14.0](https://github.com/servas-ai/bcli-public/releases/tag/v0.14.0): no code signing by design
  (the Ed25519 signature is what counts), `bcli assist` and `bcli audio` are not available on Windows, local mode on
  macOS needs Apple silicon.
