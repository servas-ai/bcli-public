**bcli v0.14.2** is a small follow-up release of the command-line client for [servas.ai](https://servas.ai)
Browser as a Service. It fixes two minor Windows issues of v0.14.0 and polishes a few messages. Same platforms,
same install paths; `bcli update` brings it to an existing install.

## Changes

- **Autofill waits for the browser extension** (Windows, all platforms): `bcli vault autofill` and
  `bcli vault bw autofill` used to fail with `bridge operation failed` / `vault operation failed` when they ran in the
  first seconds after `session create`, before the session's browser extension had connected (up to about 30 s, longest
  after a `bcli update`). They now wait up to 45 s for the page to appear in `bcli vault tabs` (`--ready-timeout`,
  `0` = no wait) and only then fill or ask for approval. If the extension does not connect, they say so:
  `browser extension not connected yet`.
- **Passphrase file with the wrong ACL is reported** (Windows): `%USERPROFILE%\.config\bcli\vault.passphrase` with an
  inherited ACL used to be ignored without a message. `bcli vault unlock` now stops with exit 7 and prints the
  one-line `icacls` fix. An empty file is reported too.
- **`bcli update --check` without a cloud environment** (fresh install, after `uninstall --purge`) now says
  `no cloud environment configured` and how to add one, instead of a confusing message about the local environment.
- **`bcli env list`** shows the release part of the server version only.
- Smaller binaries without a few internal names: the built-in identity of an internal agent mode and comments of the
  embedded database schema are no longer part of public builds.

## Install

```bash
# Linux and macOS
curl -fsSL https://raw.githubusercontent.com/servas-ai/bcli-public/main/install.sh | sh
```

```powershell
# Windows (normal PowerShell window)
irm https://raw.githubusercontent.com/servas-ai/bcli-public/main/install.ps1 | iex
```

Already installed: `bcli update` (or `brew upgrade bcli`, `scoop update bcli`). Homebrew: `brew install servas-ai/tap/bcli`.
Scoop: `scoop bucket add servas https://github.com/servas-ai/scoop-bucket`, then `scoop install servas/bcli`.
Pin this release with `sh -s -- --version v0.14.2` or `$env:BCLI_VERSION = "v0.14.2"`.
Everything else: [docs/installation.md](https://github.com/servas-ai/bcli-public/blob/main/docs/installation.md).

## Verify

The install scripts do this for you. By hand: `SHA256SUMS.sig` is the Ed25519 signature of `SHA256SUMS` with the
servas.ai CLI release key
([keys/bcli-release-ed25519.pem](https://github.com/servas-ai/bcli-public/blob/main/keys/bcli-release-ed25519.pem));
check it with OpenSSL 3 or, on Windows, with
[scripts/windows/verify-release.ps1](https://github.com/servas-ai/bcli-public/blob/main/scripts/windows/verify-release.ps1),
then check the binary against `SHA256SUMS`
([how](https://github.com/servas-ai/bcli-public/blob/main/docs/installation.md#verify-the-signature-of-sha256sums)).

## Known limitations

Unchanged from [v0.14.0](https://github.com/servas-ai/bcli-public/releases/tag/v0.14.0): no code signing by design (the
Ed25519 signature is what counts), `bcli assist` and `bcli audio` are not available on Windows, local mode on macOS
needs Apple silicon.
